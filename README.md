## About

This repository contains audio examples accompanying **StateVC: Shared-State Local Translations for Training-Free Voice Conversion**.

The listening demo presents source utterances, target-speaker reference utterances, and converted speech generated by **StateVC** and representative voice conversion systems, enabling direct qualitative comparison across methods.

> **For audio examples, please visit the [interactive listening demo](https://eurecom-asp.github.io/StateVC_listening_samples/).**

---

## StateVC

StateVC is a training-free one-shot voice conversion method operating on frozen WavLM representations. It constructs a pair-specific shared acoustic-state space and performs state-wise source-to-reference feature translations without training or fine-tuning a voice conversion model.

For implementation details, usage instructions, and technical details, see the main repository:

**[eurecom-asp/StateVC](https://github.com/eurecom-asp/StateVC)**
